Финансовый менеджер на WPF с системой безопасности

Безопасность: Аутентификация, ролевая модель (Админ/Пользователь), хеширование SHA1, защита от брутфорса.

Пользователи: Удобное управление через карточки, фильтрация, сортировка, CRUD-операции.

Финансы: Учет платежей по категориям, наглядные диаграммы расходов.

Отчетность: Многообразие диаграмм, экспорт в Excel/Word/PDF с автоматическими отчетами.

UI/UX: Смена тем, подсказки, валидация. Протестированное и надежное приложение.
